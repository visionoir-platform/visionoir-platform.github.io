# Studio adoption

Pinned upstream Euraika-Labs/Codex-Code-Game-Studios at 9a182e29f8d9b46394851830ba27213fbe4da950. The checkout contains 84 skill directories, 50 agent definitions, 47 directly listed Markdown templates and 12 shell hooks. Five MIT-licensed upstream templates and the license are retained here for new features.

The stage-detect workflow identified a released Vite website, six audio modes, a deployment workflow and no game implementation at baseline. Adoption keeps the existing build and adds an independent Canvas application entry. The help workflow routes ongoing work by missing evidence: simulation fixtures, rendered atlases, decoded sound, browser integration, then release. These workflows were read and applied from source.

The inspected bootstrap dry run proposed copying repository settings, hooks, templates and agent definitions. Applying the complete template would pin a different model and overwrite the host workflow. The project imports the documents above and applies the release gates through its own test commands. There are no machine-level installer actions or automatic upstream hook registrations.
