# Contributing to FREQUENCY

Branch from the current release. Use npm ci, run node --test tests/*.test.mjs and npm run build. Describe the musical or interaction change and supply a repeatable verification. For DSP changes give settings, format, bounds and measured output. For user interface changes check keyboard operation, touch and reduced motion.

Submit original code under the existing MIT terms or document a compatible third-party licence. Include authorship, source and usage terms for each new asset. Exclude personal photographs, work-in-progress recordings, credentials and identifiable user projects.
