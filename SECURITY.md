# Reporting a security issue

Send the affected page, browser version, impact and minimal reproduction using your own test data to visionoir.platform@gmail.com. For sensitive findings please contact the project privately before sharing the details. The team can reproduce the issue, agree a fix and coordinate public disclosure. No response time or reward is guaranteed.

FREQUENCY handles projects locally. MIDI and audio input use the browser’s permission controls. Support payments are disabled. No VISIONOIR page needs passwords, bank details or card data from a security reporter.
