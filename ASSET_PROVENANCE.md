# Provenance

The [site register](ASSETS.md) covers the six original player tracks, logo, editorial image and fonts. FREQUENCY factory instruments and sessions are created from local synthesis code and authored note data. Reference-recording titles inform the production brief. The DAW does not ship audio, stems or transcriptions of those recordings.

The Creator uses private input photographs by Flavio Giorgio Guarini. He confirmed that he generated the private Meshy model using a paid plan. The public mobile and desktop models are derivatives in a static pose. Lighting, point effects and sound-responsive deformation run in the browser. Source photos and the original rigged file remain private. [Meshy ownership terms](https://help.meshy.ai/en/articles/10137554-what-is-the-ownership-of-the-generated-models)
